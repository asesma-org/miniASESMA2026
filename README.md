# miniASESMA school 2026 (Accra, Ghana)

Website of the event: https://www.ug.edu.gh/physics/node/192

This is a collection of the hands-on material based on density-functional theory (DFT), density-functional perturbation theory (DFPT), time-dependent density-functional theory (TDDFT) and beyond using Quantum ESPRESSO [1], Siesta [2], QEpy [3] and other codes.

## Quantum Mobile:
The hands-on can be done based on the custom version of the Quantum Mobile for this school: https://github.com/marvel-nccr/quantum-mobile/blob/support/asesma/custom/README.md
After successfully installing QM, running `update` in the terminal will git clone this repository in the ~/materials folder
